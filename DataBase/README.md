# VeloStatiq DataBase

This directory is the single source of truth for VeloStatiq Sports OS data.

- `Football/` contains association-football player and match archives.
- `FormulaOne/` contains historical race, timing, standings, and circuit data.
- `cache/espn/` is reserved for sanitized ESPN Fantasy Football (NFL) API responses.
- `cache/football/` stores the latest normalized upcoming fixtures for offline fallback.
- `sources/football-providers.json` documents each free football provider, its role, and attribution.
- `sources/f1-model.json` documents every Formula One prediction output and the local datasets that feed it.
- `sources/champions-league-2026-27.json` stores the UEFA-attributed competition format, milestones, and currently published play-off fixtures used by the football workspace.
- `index.json` is generated by `npm run data:index` and powers low-latency search and catalog APIs.

The Formula One collection also includes the newly added lap, stint, tyre degradation, pit-strategy, team-strategy, and season-comparison derived datasets. They are included automatically in the indexed file and byte totals.

Do not store ESPN `espn_s2` or `SWID` cookies in this directory. Configure secrets through environment variables only.
